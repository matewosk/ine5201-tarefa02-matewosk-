# Calculadora

Calculadora de desktop feita em Python com interface gráfica Tkinter.

## Requisitos

- Python 3 com Tkinter disponível.

Não são necessárias dependências externas.

## Como executar

No PowerShell, dentro da pasta do projeto, execute:

```powershell
python calc.py
```

## Recursos

- Soma, subtração, multiplicação e divisão.
- Entradas numéricas com suporte a vírgula ou ponto como separador decimal.
- O resultado passa a ser o primeiro número da próxima operação; o segundo número permanece.
- Histórico das operações da sessão, exibido ao lado da calculadora.
